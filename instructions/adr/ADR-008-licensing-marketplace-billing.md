# ADR-008. Лицензии, маркет модулей и оплата

- **Статус:** утверждено 2026-10-29
- **Дата:** 2026-10-29
- **Связанные:** ADR-001, ADR-003, ADR-009

## Контекст

- Маркет модулей нужен и в Платформе (CRM), и в админке клиента. Модель — как в WordPress.
- Клиент покупает модуль и сразу его применяет. Может заказать уникальную разработку, после которой модуль попадает в маркет.
- Нужны **обе модели продажи** (подписка и разовая покупка) и **оба способа оплаты** (счёт через CRM и онлайн-оплата).
- Сайт клиента не должен перестать работать из-за проблем с лицензией или из-за недоступности Платформы.

## Решение

### Лицензия

Лицензия — это подписанный токен (Ed25519), который проверяется **офлайн** внутри ячейки:

```json
{
  "lic": "lic_7f3a…",
  "cell": "client-a",
  "domain": "example.ru",
  "module": "forms",
  "edition": "pro",
  "model": "subscription",
  "validUntil": "2026-12-01",
  "graceDays": 14,
  "exit": false
}
```

- Ключ подписи хранится только в Платформе. В ячейке лежит публичный ключ.
- Ячейка получает обновлённые лицензии через agent вместе с желаемым состоянием.
- Без связи с Платформой лицензия продолжает действовать до `validUntil`, а затем ещё `graceDays`.

### Что происходит при истечении лицензии

| Состояние | Публичный сайт | Админка |
|---|---|---|
| Действует | Работает | Работает |
| Льготный период | Работает | Работает, баннер «оплатите до …» |
| Истекла | **Работает** (данные модуля показываются) | Модуль **только для чтения**, модальное окно «Модуль заблокирован», кнопка «Продлить» |
| Отозвана (kill switch, ADR-003) | Блоки модуля показывают fallback | Модуль выключен, с объяснением |

**Публичный сайт никогда не ломается из-за лицензии.** Это защищает репутацию агентства и не делает клиента заложником.

### Модели продажи

- `free` — бесплатный модуль;
- `one-time` — разовая покупка: бессрочная лицензия на мажорную версию, обновления в её пределах;
- `subscription` — помесячно или помесячно-годовая, с автопродлением.

### Оплата

| Способ | Поток |
|---|---|
| **Счёт через CRM** | Покупка → `Invoice` в renoteOS → оплата отмечена → Платформа выпускает лицензию → agent доставляет |
| **Онлайн в админке** | Покупка → платёжный адаптер (ЮKassa, CloudPayments или СБП; выбор при реализации) → webhook в Платформу → `Invoice` в статусе «оплачен» → лицензия |

В обоих случаях источник истины по деньгам — `Invoice` в CRM. Платёжный провайдер подключается через адаптер с интерфейсом `createPayment / handleWebhook / refund`. Webhook проверяется по подписи и обрабатывается идемпотентно.

### Каталог

- Каталог хранится в Платформе: модуль, версии, совместимость с ядром, цены, описание, скриншоты, статус ревью.
- Админка клиента получает каталог от Платформы по токену ячейки. Если Платформа недоступна, показывается закэшированный каталог с пометкой «покупка временно недоступна».
- **Установка в один клик.** Покупка меняет желаемое состояние ячейки (ADR-006), agent ставит модуль. Клиент видит прогресс установки.

### Заказ уникальной разработки

Кнопка «Заказать модуль» в админке создаёт `Lead` или `Task` в CRM с описанием от клиента. Разработанный модуль публикуется:

- как **приватный** — виден только этому клиенту;
- или, по договорённости с клиентом, в **общий маркет**.

### Публикация модуля в маркет

1. Сборка в CI.
2. SBOM.
3. Тесты совместимости с ядром N-1 и N.
4. Проверка манифеста и прав.
5. Ревью человеком.
6. **Подпись артефакта.**
7. Публикация.

Ячейка ставит только модули с валидной подписью агентства.

## Рассмотренные альтернативы

| Вариант | Почему отклонён |
|---|---|
| Онлайн-проверка лицензии при каждом запросе | Падение Платформы ломает все сайты |
| Блокировать сайт при неоплате | Удар по репутации агентства, клиент становится заложником, юридические риски |
| Отдельный биллинг вне CRM | Дублирует `Invoice` и учёт денег |

## Последствия

- Нужны модули лицензий и каталога в Платформе и проверка лицензий в ядре ячейки (часть SDK, ADR-003).
- Ключ подписи — критичный секрет. Хранится так же, как KEK (ADR-004), с процедурой ротации.
- Флаг `exit: true` используется при передаче проекта (ADR-009).
